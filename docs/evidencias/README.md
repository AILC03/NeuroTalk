# Evidencias visuales de la revisión web

Capturas de escritorio tomadas sobre backend/base de pruebas, con cuenta y conversación ficticias. No contienen contraseñas, tokens ni datos de usuarios reales. No son capturas Android ni ejemplos de IA real.

- `login-web.png`: acceso con la paleta y tarjetas basadas en Figma.
- `chat-web.png`: mensaje persistido del usuario y respuesta del simulador.
- `progreso-web.png`: indicadores derivados de la práctica de revisión. El tiempo mostrado proviene de los intervalos reales de esa prueba prolongada, no de un benchmark ni de datos de ejemplo predefinidos.

Las capturas representan momentos de revisión; el código puede contener ajustes posteriores menores de texto/accesibilidad. Ver `../registro-desarrollo.md` para límites y pruebas ejecutadas.
