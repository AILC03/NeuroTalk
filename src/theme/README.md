# theme — lenguaje visual

`tokens.ts` define colores comunes y paletas por categoría a partir de la referencia visual Figma: fondo crema, superficies blancas, verde principal, tintes lavanda/académico y naranja/laboral.

No contiene datos del usuario ni lógica de negocio. Los estilos tipográficos, espacios y tarjetas compartidos están en `components/ui.tsx`. Mantener contraste legible; el color no debe ser la única indicación de dificultad, estado o error.

No se extrajeron tokens de la API de Figma: es una implementación visual basada en la revisión del archivo y los mockups del Avance 1. Medidas y fuentes no se presentan como coincidencia pixel-perfect.
